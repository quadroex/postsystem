# Індекси

У `db/004_indexes.sql` створено індекси двох методів доступу: **B-tree** і **GIN**.

| Індекс | Призначення |
|---|---|
| `ux_customers_active_email` | Унікальний email серед активних клієнтів; архівний запис зберігається. |
| `ix_shipments_active_status` | Черга активних відправлень за станом і датою. |
| `ix_shipments_sender`, `ix_shipments_recipient` | Вибірки відправлень клієнта. |
| `ix_parcels_shipment`, `ix_payments_shipment` | Пакунки й оплати конкретного відправлення. |
| `ix_events_shipment_time` | Історія подій у хронологічному порядку. |
| `ix_audit_entity_time` | Історія змін запису. |
| `ix_customers_search` (GIN) | Повнотекстовий пошук клієнтів за ім’ям та email. |
| `ix_audit_new_data` (GIN) | Пошук у JSONB журналу через `@>`. |

Первинні та звичайні унікальні ключі також мають автоматичні B-tree індекси, зокрема номер відстеження.

Виконати `db/explain_indexes.sql`: перша вибірка показує методи доступу, решта — плани реальних запитів. На малому наборі даних PostgreSQL може вибрати послідовне сканування; це очікувана поведінка планувальника.
